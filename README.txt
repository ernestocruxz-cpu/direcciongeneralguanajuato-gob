Proyecto: Pago de infracciones en materia de movilidad

Abre index.html en tu navegador para ver la pagina.

Imagenes que usa el proyecto:
- assets/logo-gobierno.png
- assets/sello-igualdad.png
- assets/banner-pago-infracciones.png

Si despues quieres cambiar las imagenes, ponlas en la carpeta assets con esos mismos nombres.

Archivos principales:
- index.html
- admin/alta.html
- admin/login.html
- admin/listado.html
- backend/
- css/styles.css
- css/admin.css
- js/main.js
- js/admin-alta.js

Modulo interno de alta:
- No tiene enlace desde la pagina principal.
- Login modelado: /admin/login.html
- Alta: /admin/alta.html
- Listado: /admin/listado.html
- De momento guarda la captura en localStorage del navegador.
- Credenciales demo del login: admin / admin123

Backend:
- Carpeta: backend/
- SQL PostgreSQL: backend/database/schema.sql y backend/database/seed.sql
- API Node/Express: backend/src/
